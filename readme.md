
# ✨ LUMINA — AI Powered Learning & Quiz Platform

Lumina is a modern AI-powered web application built with **Flask + JavaScript + Custom UI Design**.  
It provides interactive learning tools like explanations, quizzes, MCQs, and AI-generated content in a beautiful dark-themed interface.

---

## 🚀 Features

- 🤖 AI-powered explanations (LLM integration)
- 🧠 Interactive MCQ & quiz system
- 📚 AI summarizer & explain mode
- 🎨 Premium dark UI (Obsidian + Gold theme)
- 🖱️ Custom cursor + interactive animations
- ✨ Smooth card hover & 3D effects
- ⚡ Fast Flask backend with static frontend rendering

---
## How to Run Locally

1. Clone the repo
   ```
   git clone https://github.com/waniyafarooq/LUMINA.git
   cd neuralearn
   ```

2. Install dependencies
   ```
   pip install -r requirements.txt
   ```

3. Create a `.env` file and add your Groq API key
   ```
   GROQ_API_KEY=your_key_here
   ```

4. Run the app
   ```
   python app.py
   ```



## Getting a Free Groq API Key

1. Go to [console.groq.com](https://console.groq.com)
2. Sign up and go to API Keys
3. Create a new key and paste it in your `.env` file
